muxr — Tablet

The four phone screens re-laid for a tablet, on Glyph, built only from what the shipped app and muxrd can supply today. Sessions becomes master-detail, the "panes & tabs" side sheet becomes a docked rail, Settings becomes a card grid of its six real groups, and Connect earns its width with the returning-user path beside the form. Every frame below is a CSS container: switch the frame size and the same markup collapses the way the size-class rule below says it should. Interactive bits are marked with a demo strip under each frame.

The rail is the phone's side sheet docked: same space card, tab rect and pane pill, same guides, but it never closes, animates only on a user expand, and follows server-side focus from the layout poll. It gains the session name and backend the phone never shows, a float tag and an exited mark the data already carries, a bell on the tab, a hover ⋯ per row for rename (no close or kill, those RPCs are not wired), and a single footer action, detach; the replay button is gone, it was a test seam. The kebab is now a real menu. The card gets the Glyph breadcrumb, the three-state link strip, and a read-only chip. The key bar is persistent on wide (a hardware keyboard produces no inset), keeps Shift, adds Home, End and an Fn row, and uses the inverted-T cluster. Immersive removes the bar and collapses the rail to the mini rail with tooltips, so navigation is never lost.

Six groups of two to six rows do not need master-detail, so the grid is the whole screen and the shell bar keeps its server settings title and back. The groups are the app's own: connection (with the three real TLS values and a new latency row), auth tokens (scope chips, revoke with its scramble, create gated under read-only), saved servers and muxr pro, both missing from v0.2, terminal appearance with the size range widened for tablets, and session poll. Invented rows are gone: auto-reconnect is automatic backoff, and Alt always sends the escape prefix. The paywall, confirms and the create-token dialog open at dialog width, never full-bleed.
decisions this mock takes
no global rail

Dropped in the 2026-09-30 revision: a 56px strip carrying a logo and two buttons paid for its width with nothing the shell bar does not already offer. The shell bar is the whole navigation on every class, so no Glyph navigation rail is needed and the terminal page does not have to be retained across routes for this design to ship.

the shell bar stays

One Glyph app bar over every in-shell route, exactly the phone's RouteMeta adapter: brand or back on the left, title centred, the terminal menu on the right. The gear stays on the Sessions bar on every class, as on the phone. Connect stays bar-less.

back, per screen

Back on Sessions still raises "Disconnect from server?"; back on Terminal or Settings returns to Sessions.

tap semantics on sessions

Phone tap attaches; tablet tap selects, attach is the header button or a double-tap. Selection tracks the session id across the poll so a rename keeps it.

key bar on wide

Persistent, toggled from the terminal menu, because a hardware keyboard produces no keyboard inset and the phone bar would never appear. Shift stays; Home, End and F-keys are added and need byte mappings.

read-only everywhere

A read-only chip in the sessions strip, the rail header and the card header. Add rows withdrawn, renames refused, no key bar, the grid never focuses; selection, copy, scroll, browse and attach keep working.

what has to exist for this to ship
new in glyph
  • docked panel for the terminal rail: Glyph's side sheet is modal-only and pinned to the right edge
  • two-pane container with a fixed side width and a flexible detail, no divider drag in v1
  • sheet max width on wide, or a dialog-sized variant, for the paywall, QR, manage, picker, token reveal and font sheets
  • reused as-is: menu, breadcrumb, stat card, empty state, skeleton, tooltip, alert, list item, segmented control
new app work
  • per-selection layout poll on Sessions for the preview and tree; attach-into-pane reuses the resume slot
  • render dropped fields: session age, bell, attached-by-me; the latency row in Settings
  • backend picker in the new-session dialog: the wire's create request already takes one
  • rail behaviour: no close on commit, resting state, follow server-side focus, per-row menu
  • key bar: persistent mode, Home, End, F-keys, hardware PgUp and PgDn
  • font size range beyond 14px on wide; inline field errors on Connect; a Retry on first-load failure
  • iOS: the target moves from iPhone-only to universal, which adds iPad screenshots to the listing
  • palette: hover, overlay, glow, warning and error faint and border tints do not exist in the Rust palette yet
